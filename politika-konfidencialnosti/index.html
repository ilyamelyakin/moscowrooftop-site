Политика обработки персональных данных

Документ описывает, какие данные сайт moscowrooftop.ru получает от посетителей, зачем они нужны и что с ними происходит. Мы собираем минимум: только то, без чего невозможно связаться с вами по заявке.

Кто обрабатывает данные

Оператор — владелец сайта moscowrooftop.ru, организатор прогулок по крышам Москвы. Связаться по любому вопросу об обработке данных можно в Telegram: @MoscowRoofTopBot.

Какие данные собираются

Через форму заявки на сайте:

  • имя, которое вы указали;
  • способ связи и контакт — имя пользователя в Telegram либо номер телефона;
  • детали заявки: выбранная крыша, дата, время, количество участников, комментарий.

Дополнительно сайт использует системы веб-аналитики Яндекс Метрика и Google Analytics, которые собирают обезличенные данные о посещении: технические параметры устройства и браузера, источник перехода, просмотренные страницы. Эти данные не позволяют идентифицировать вас лично.

Зачем они нужны

Единственная цель — связаться с вами по оставленной заявке: подтвердить свободное время, согласовать детали встречи и сообщить адрес. Мы не используем контакты для рассылок и не отправляем рекламные сообщения.

Кому передаются данные

Содержимое заявки доставляется оператору сообщением в Telegram — то есть проходит через сервис Telegram Messenger LLP. Другим лицам данные не передаются и не продаются. Сайт размещён на инфраструктуре Cloudflare; техническая обработка запроса происходит на её серверах.

Сколько хранятся

Заявка хранится в переписке столько, сколько нужно для организации прогулки и ответов на последующие вопросы. По вашему запросу переписка с вашими данными удаляется.

Как отозвать согласие или удалить данные

Напишите в Telegram-бот — мы удалим вашу заявку и контакты. Отозвать согласие можно в любой момент, без объяснения причин.

Cookies и аналитика

Сайт использует файлы cookie и локальное хранилище браузера, чтобы запоминать выбранную крышу и источник перехода. Отключить это можно в настройках браузера — на работу сайта это почти не влияет. Отказаться от сбора данных Яндекс Метрикой можно через официальный блокировщик Яндекса.

Согласие

Отмечая галочку согласия в форме заявки, вы подтверждаете, что ознакомились с этим документом и согласны на обработку указанных данных для связи по заявке.

Остались вопросы?

Напишите в Telegram — ответим и, если нужно, удалим ваши данные.
